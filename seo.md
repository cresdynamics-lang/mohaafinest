### TASK 2 — On-Page SEO Optimization

For **every page** on the website (homepage, collections page, each product/category page, about page, contact page, blog if any), rewrite or optimize the following:

#### 2a. Title Tags
- Format: `Primary Keyword | Secondary Keyword — Mohaa Finest Curtains`
- Keep under 60 characters
- Include location (Nairobi/Kenya) where natural
- Make each title unique

#### 2b. Meta Descriptions
- 150–160 characters
- Include primary keyword + location + call to action (e.g. "WhatsApp for a free quote")
- Make each description unique and compelling

#### 2c. Heading Tags (H1, H2, H3)
- One H1 per page containing the primary keyword
- H2s for each section using secondary keywords
- H3s for product variants or sub-sections
- Rewrite all headings to be keyword-rich and natural

#### 2d. Body Content / Product Descriptions
For each product/category page, write at least **300 words** of unique, keyword-optimized content covering:
- What the product is
- Benefits and features
- Why customers in Nairobi/Kenya love it
- Pricing context (e.g. "affordable curtains from KES 1,500 per meter")
- How to order (WhatsApp, visit Moyale Mall, free measurement)
- FAQ section with 3–5 questions per page

#### 2e. Image Alt Text
Write descriptive, keyword-rich alt text for every image on the site. Format: `[descriptive phrase] — Mohaa Finest Curtains Nairobi`

#### 2f. Internal Linking
Create an internal linking strategy. List which pages should link to which, using keyword-rich anchor text (e.g. "buy blackout curtains in Nairobi" linking to the blackout curtains page).

#### 2g. URL Slugs
Audit all URLs. Recommend clean, keyword-rich slugs. E.g.:
- `/blackout-curtains-nairobi`

- `/sheer-curtains-kenya`

### TASK 3 — Technical SEO Audit & Fixes

1. **Page Speed** — identify any slow-loading elements; recommend image compression (WebP format), lazy loading, and caching strategies

   - `LocalBusiness` schema with name, address (Moyale Mall, Eastleigh, Nairobi), phone, opening hours, geo coordinates

   - `FAQPage` schema for FAQ sections
4. **XML Sitemap** — generate a complete sitemap.xml and recommend submission to Google Search Console
5. **Robots.txt** — write an optimized robots.txt file
6. **Canonical Tags** — add canonical tags to all pages to prevent duplicate content
7. **Open Graph & Twitter Cards** — add OG tags for all pages so links shared on WhatsApp and social media show rich previews

9. **Core Web Vitals** — recommendations to improve LCP, FID/INP, and CLS scores
10. **404 Errors & Redirects** — audit for broken links and set up 301 redirects where needed
